3. ARQUITECTURA DE DATOS & PROTOCOLOS DE COMUNICACIÓN

  • Colección Principal Firestore: terjamanco_site
  • Documento Principal de Estado: main_content (Almacena info, hero, sedes, servicios, productos, paquetes, galería, reseñas, faqs y configuración de audio).
  • Protocolo de Transmisión en Vivo: Google Firestore WebSocket gRPC / WebChannel + Server-Sent Events (SSE) para clientes conectados.
  • Almacenamiento de Sesión: LocalStorage seguro para tokens JWT de sesión administrativa.

4. SEGURIDAD, INTEGRIDAD Y PROTECCIÓN DE DATOS

Área de Seguridad Estrategia Implementada
Autenticación Admin Tokens JWT firmados con clave secreta criptográfica (JWT_SECRET).
Protección de Claves Encriptación unidireccional de contraseñas con algoritmo bcryptjs.
Protección contra Inyección / XSS Sanitización automática en React DOM Virtual Tree y serialización estricta de JSON.
Subida de Archivos Validación de tipos MIME (image/jpeg, image/png, image/webp, audio/mpeg) y sanitización de nombres de archivo.
Reglas de Seguridad Cloud Políticas granulares en Firestore y Storage para lectura pública y protección de escritura.
Cifrado en Tránsito HTTPS / TLS 1.3 en todos los endpoints de Netlify y Google Cloud.

5. REQUISITOS DEL SISTEMA

5.1 Hosting y Servidor

  • Hosting Estático: Netlify (CDN Global, soporte de netlify.toml para redirecciones SPA /* -> /index.html).
  • Google Firebase: Proyecto activo en Cloud Firestore y Firebase Storage (Plan Spark Gratuito o Plan Blaze).
  • Node.js (para desarrollo / backend local): Node.js v18.0.0 o superior, npm v9.0.0 o superior.

5.2 Compatibilidad de Navegadores de Clientes

  • Chrome 90+ Safari 14+ (iOS / macOS) Firefox 88+ Edge 90+ Android WebView / Chrome Mobile
